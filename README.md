# Хроноквест · OPERATION: BIRTHDAY

PWA-поздравление на день рождения Гули (Хомяка) — 24 ноября.

Сеттинг: средневековье + футуристическое будущее. Уровни открываются по цепочке; после полного прохождения — свободный выбор.

## Запуск

```bash
npm install
npm run dev
```

С телефона локально — по Network-ссылке в той же Wi‑Fi сети.

```bash
npm run build
npm run preview
```

## GitHub Pages

Сайт: https://taa08.github.io/homyak-quest/

Обновление после правок:

```bash
npm run build
npx gh-pages -d dist -b gh-pages
```

## Кампания

1. Зернохранилище — лови зёрна  
2. Неборазорение — side-scroller шутер  
3. Донжон корон — короны и мышеловки  
4. Кристальный архив — память  
5. Голограммы — фото  
6. Летопись — факты  
7. Допрос агента — викторина  
8. Коронация — финал  

## Что править первым

[`src/data/content.ts`](src/data/content.ts) — сюжет, факты, викторина, подписи, финал.

Фото: `public/photos/` + пути в `content.ts`.

## Dev-режим

В [`src/config.ts`](src/config.ts) флаг `DEV_MODE = true` включает кнопку
«dev · пройти без очков». Перед подарком поставь `false`.
